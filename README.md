# Personal Notes

A local-first, Keep-style notes app for Android (Kotlin, Jetpack Compose, Room).

- Notes and checklists, autosaved on the device
- Pin, color, labels, search, archive, trash (30-day auto-delete)
- Grid or list view
- Backup and restore through a single JSON file (save it to Google Drive from the file picker)

Every push to `main` builds the APK with GitHub Actions and publishes it to the `latest` release.
